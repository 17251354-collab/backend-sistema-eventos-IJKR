# Sistema de Gerenciamento de Eventos Acadêmicos

API REST completa para gerenciamento de eventos acadêmicos, desenvolvida com FastAPI. O sistema implementa autenticação segura via JWT, controle de acesso baseado em perfis (RBAC) e uma suíte de testes automatizados.

## 🚀 Tecnologias Utilizadas
* **Python 3.12+** - Linguagem base.
* **FastAPI** - Framework web moderno e de alta performance.
* **SQLAlchemy** - ORM para mapeamento e comunicação com o banco.
* **SQLite** - Banco de dados relacional leve (utilizado em desenvolvimento).
* **Alembic** - Ferramenta para controle de migrations do banco.
* **Pytest** - Framework para testes automatizados.
* **Passlib / Bcrypt** - Criptografia e hash seguro de senhas.
* **Python-Jose** - Geração e validação de tokens JWT.
